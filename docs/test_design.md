# テスト設計（Study Log App）

## 入力チェック
- 日付が入力されているか確認する
- 科目が入力されているか確認する
- 学習時間が入力されているか確認する
- 学習時間が整数で入力されているか確認する
- 学習時間が1〜1440の範囲で入力されているか確認する
- 学習時間に文字列を入力した場合の動作を確認する
- 学習時間に小数を入力した場合の動作を確認する
- 学習時間に0を入力した場合の動作を確認する
- 学習時間に1441以上を入力した場合の動作を確認する
- 存在しない日付を入力した場合の動作を確認する

## データ保存
- 正しく入力した場合にCSVに保存されるか確認する
- 入力エラーがある場合にCSVに保存されないか確認する
- 複数回入力した場合にデータが追記されるか確認する（既存データが消えないこと）

## 表示
- 保存成功メッセージが表示されるか確認する
- 入力エラー時にエラーメッセージが表示されるか確認する

## 検索
- 科目を入力して検索した場合に、入力した科目を含む記録が表示されるか確認する
- 開始日と終了日を入力して検索した場合に、指定した日付範囲の記録が表示されるか確認する
- 開始日が終了日より後の場合に、エラーメッセージが表示されるか確認する
- 検索条件を入力しない場合に、保存済みの学習記録が全件表示されるか確認する
- 一致しない条件で検索した場合に、「該当する記録がありません。」が表示されるか確認する
