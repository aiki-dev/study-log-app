# 不具合報告（Study Log App）

関連テストケース : TC-12

## 1. 概要
存在しない日付を入力した場合、サーバー側のエラーメッセージではなく、
ブラウザのバリデーションメッセージが表示される。

## 2. 発生環境
OS：Windows 11  
Python：3.14.3  
Flask：3.1.2  
Browser：Microsoft Edge 146  

## 3. 再現手順
1. アプリを起動する
2. 日付に「2026-02-30」を入力
3. 科目に「数学」を入力
4. 学習時間に「60」を入力
5. 送信ボタンを押す

## 4. 期待結果
「正しい日付を入力してください。」というエラーメッセージが表示される。

## 5. 実際の結果
ブラウザのバリデーションにより  
「有効な値を入力してください。」と表示され、フォームが送信されない。

## 6. 影響範囲
存在しない日付入力時のエラーメッセージ表示。

## 7. 優先度
低

理由  
ブラウザ側で入力自体が防止されているため、
致命的な問題ではない。
