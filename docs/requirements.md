# 要件定義書（Study Log App）

## 1. 概要

本アプリは、学習時間を記録して保存できるWebアプリケーションである。
ユーザーは日付・科目・学習時間（分）を入力し、記録を保存できる。
また、保存した学習記録を科目や日付範囲で検索できる。

---

## 2. 入力項目

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| 日付 | date | 〇 | 学習した日（YYYY-MM-DD形式） |
| 科目 | string | 〇 | 学習内容 |
| 学習時間 | integer | 〇 | 分単位の整数 |

---

## 3. 入力ルール

- 日付・科目・学習時間はすべて必須項目とする
- いずれかが空欄の場合はエラーとする
- 日付は YYYY-MM-DD 形式とする
- 存在しない日付（例: 2026-02-30）はエラーとする
- 学習時間は整数のみ入力可能とする
- 学習時間は 1〜1440 の範囲とする

---

## 4. 保存ルール

- データはCSVファイルに保存する（将来的にSQLiteへ移行予定）
- 保存形式：日付,科目,学習時間
- 保存は追記方式とし、既存データは削除しない
- 正常時のみ保存される

---

## 5. エラー表示ルール

- バリデーションエラー時は画面にエラーメッセージを表示する
- エラー発生時は成功メッセージを表示しないこと
- エラー時はデータを保存しない
- 検索時に開始日が終了日より後の場合は、エラーメッセージを表示する

---

## 6. 用語定義

学習時間：分単位の整数値

---

## 7. 受入基準（Acceptance Criteria）

### AC-01
Given 正しい値を入力  
When 保存ボタンを押す  
Then データが保存され、成功メッセージが表示される

### AC-02
Given 空欄入力  
When 保存ボタンを押す  
Then エラーメッセージが表示され、保存されない

### AC-03
Given 学習時間に文字を入力  
When 保存ボタンを押す  
Then エラーが表示され、保存されない

### AC-04
Given 学習時間が範囲外（1未満 または 1440超）  
When 保存ボタンを押す  
Then エラーが表示され、保存されない

### AC-05
Given 正しい値で保存済み  
When CSVファイルを確認する  
Then 新しいレコードが1件追加されている

### AC-06
Given 存在しない日付を入力（例: 2026-02-30）  
When 保存ボタンを押す  
Then エラーが表示され、保存されない

### AC-07
Given 保存済みの学習記録がある  
When 科目を入力して検索する  
Then 入力した科目を含む記録が表示される

### AC-08
Given 保存済みの学習記録がある  
When 開始日と終了日を入力して検索する  
Then 指定した日付範囲の記録が表示される

### AC-09
Given 開始日が終了日より後になっている  
When 検索ボタンを押す  
Then エラーメッセージが表示される

### AC-10
Given 保存済みの学習記録がある  
When 検索条件を入力せず検索する  
Then 保存済みの学習記録が全件表示される

### AC-11
Given 保存済みの学習記録がある  
When 一致しない条件で検索する  
Then 「該当する記録がありません。」が表示される
