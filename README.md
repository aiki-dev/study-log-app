# 学習ログアプリ

PythonとFlaskを使って作成した、学習時間を記録するWebアプリです。

## 作成目的
日々の勉強時間を記録し、継続的に学習できるようにするために作成しました。
また、Flaskを用いたWebアプリの基本的な仕組みを理解することも目的としています。
さらに、本アプリをテスト対象（SUT）として、要件定義から不具合報告までのテスト工程を一通り実施しました。

## 使用技術
- Python 3.14.3
- Flask 3.1.2
- HTML
- CSVファイル
- Git / GitHub

## 機能
- 学習記録の登録（日付・科目・学習時間）
- 入力内容のチェック（空欄・日付・数値・範囲）
- 正常時はCSVファイルに1行追加される
- 入力エラー時はメッセージが表示され、保存されない

## 工夫した点
- 入力内容のチェックを行い、間違ったデータが保存されないようにしました。
- 入力に問題がある場合はエラーメッセージを表示し、保存されないようにしました。
- データはCSVファイルに保存し、あとから中身を確認しやすいようにしました。
- このアプリを使って、要件定義から不具合報告まで一通りのテストを行いました。

## 起動方法（Windows）

1. 仮想環境を作成
   python -m venv venv
2. 仮想環境を有効化
   venv\Scripts\activate
3. Flaskをインストール
   pip install flask
4. アプリを起動
   python app.py
5. ブラウザでアクセス
   http://127.0.0.1:5000
